## Core thesis

> AI does not eliminate the bottleneck in scholarly credit settlement; it changes the unit and the locus of settlement.

Credit settlement = registration / attribution / acceptance; five-dimensional credit vector (originality, evidence quality, verification, maintenance, downstream use — never summed); staged settlement (0.1 → 1.0).
